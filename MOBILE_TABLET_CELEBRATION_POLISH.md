# Mobile / Tablet / Celebration Polish

Kemasan tambahan ini memfokuskan 3 perkara:

1. **Paparan iPhone / Android kecil**
   - Padding, ruang, saiz kad, dan butang disentuh diperkemaskan.
   - Kuiz dipadatkan supaya lebih muat pada skrin kecil.
   - Susun atur dashboard penjaga diperkemas supaya lebih fokus pada mobile.
   - `safe-area` untuk peranti bertakuk (notch) diberi perhatian.

2. **Paparan tablet**
   - Grid kandungan diseimbangkan semula.
   - Dashboard dan paparan kuiz diberi susun atur yang lebih lapang dan stabil.
   - Beberapa seksyen penting menggunakan 2 kolum pada tablet untuk paparan yang lebih kemas.

3. **Animasi celebration lebih meriah**
   - Celebration kini mempunyai:
     - badge tengah “🎉 Hebat! 🎉”
     - confetti/rain
     - burst/radial particles
     - light rays / glow
     - reward shimmer pada paparan jawapan betul
