# CilikGo Agent Dashboard 2.0

Ditambah:
- Link referral unik + butang Salin Link.
- Jumlah Penjaga yang mendaftar melalui Agent.
- Senarai referral dan carian.
- Jumlah order/pembelian berjaya.
- Nilai jualan.
- Conversion referral → pembelian.
- Komisen keseluruhan, pending dan dibayar.
- Sejarah jualan dan komisen.
- Responsive untuk telefon.

## ToyyibPay
ToyyibPay kekal KIV. Referral/pendaftaran boleh direkod sekarang, tetapi statistik jualan dan komisen sebenar hanya akan terisi apabila backend pembayaran diaktifkan.

## Nota
Dashboard membaca `users.referredByCode`, `orders.agentUid/agentRef`, dan `commissions.agentUid`.
