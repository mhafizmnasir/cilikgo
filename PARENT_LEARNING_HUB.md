# CilikGo — Learning Hub Penjaga

## Aliran baharu
Dashboard Penjaga → Modul 3M → Learning Hub → pilih Membaca/Menulis/Mengira → pilih Level → belajar.

Halaman demo awam tidak diubah dan kekal untuk pelawat.

## Learning Hub memaparkan
- Profil anak aktif.
- Rank dan jumlah bintang keseluruhan.
- Kad Membaca, Menulis dan Mengira.
- Jumlah bintang setiap modul.
- Level semasa yang terbuka.
- Status Level 1–3 (selesai / semasa / terkunci).
- Rekod terbaik pada level semasa.
- Butang Mula Belajar / Teruskan Belajar.

Learning Hub menggunakan progression Learning System 2.0 dan subscription enforcement sedia ada.

## UAT
1. Login Penjaga dengan subscription aktif.
2. Dashboard → Modul 3M mesti membuka Learning Hub, bukan homepage demo.
3. Nama/avatar anak aktif mesti betul.
4. Klik Membaca/Menulis/Mengira → Level Picker Learning System 2.0.
5. Tukar profil anak di Dashboard → buka Learning Hub semula → progress mesti mengikut anak tersebut.
6. Menu Modul 3M pada homepage untuk pelawat masih menunjukkan demo.
