# CilikGo — Paparan Pelajar Interaktif

Penambahbaikan:
- Hero pelajar dengan ucapan personal dan butang Sambung Belajar.
- XP dan Level berdasarkan jumlah bintang.
- Misi Harian 3 latihan dengan progress ring.
- Streak belajar dikira daripada rekod hari berturut-turut.
- 4 kad subjek lebih berwarna dan interaktif.
- Progress setiap subjek, sesi, skor terbaik dan topik dikuasai.
- Pencapaian Pelajar, jumlah bintang, jumlah sesi dan streak.
- Tip belajar ringkas.
- Paparan responsive desktop/mobile.
- Soalan/Firestore tidak diubah; hanya pengalaman Pelajar.

Tiada perubahan Firestore Rules diperlukan.
